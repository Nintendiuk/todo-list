## About

**Django Todo List** is a task management web application built with Django 5 and PostgreSQL. It helps you organize daily work by creating tasks with optional deadlines, grouping them by tags, and tracking completion status.

The project demonstrates professional Django development practices:
- **Class-Based Views (CBV)** throughout — no function-based views
- **Split settings** (`base` / `dev` / `prod`) for clean environment management  
- **Test-Driven Development** — full test suite covering CRUD, toggle logic, and sorting
- **"Dark Luxury" UI** — custom CSS theme, no third-party form libraries
- **DRY principle** — shared base template, reusable form card and confirm card components

Built as a learning project to showcase a clean Django project structure that scales.
